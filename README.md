## 📖 О игре

**«Нечто» (Stay Away!)** — игра с тайными ролями, дедукцией, блефом и выживанием для 4–12 игроков.

Один из участников тайным образом становится **Главным Монстром (Нечто)**, а остальные — **Людьми**. Задача Нечто — скрывать свою личность и тайно заражать других игроков через обязательные обмены картами. Задача Людей — вычислить монстра при помощи карт проверок («Анализ», «Подозрение», «Виски») и сожрать его Огнемётом!

## ✨ Ключевые Возможности

- 🌐 **Мультиплеер в реальном времени:** Мгновенный обмен данными через WebSockets (Socket.io).
- 🎲 **Официальный баланс колоды:** Точная генерация количества карт и карт Паники для любого состава от 4 до 12 игроков строго по правилам настольной игры.
- 🎨 **Оригинальные арты карт:** Выделенные HD-изображения всех карт и двух видов рубашек («Stay Away!» и «Паника»).
- 🤖 **Встроенный контроллер Ботов:** Возможность создавать тестовых ботов и пересаживаться в их кресла для игры малым составом или отладки.
- 🖼️ **2D-Игровой Стол:**
  - Динамическая овальная рассадка участников.
  - Визуальные оверлеи **Заколоченных Дверей 🚪** в проходах между креслами.
  - Бляхи **Карантина ☣️** над аватарами изолированных игроков.
- 🛡️ **Фаза Защиты и Реакций:**
  - Отмена тайного обмена картой *«Нет уж, спасибо!»*.
  - Защита от атак Огнемётом картами *«Мимо!»* и *«Никакого шашлыка!»*.
- 🔍 **Спец-эффекты карт:**
  - **Анализ:** Персональный просмотр всей руки соседа в секретном модальном окне.
  - **Виски:** Публичный показ всех своих карт в реальном времени.
  - **Топор:** Разрушение заколоченных дверей и вызволение из карантина.
- 🏆 **Экран Победы & Role Reveal:** Анимированный финал партии со срыванием масок и полным раскрытием тайных ролей всех участников.

## 🛠️ Стек Технологий

### **Frontend**

* **Framework:** [React 18](https://reactjs.org/) + [Vite](https://vitejs.dev/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Network:** `socket.io-client`

### **Backend**

* **Runtime:** [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/)
* **Realtime Engine:** [Socket.io](https://socket.io/)
* **Language:** TypeScript
* **State Management:** In-Memory Game State Machine

### **Assets & Processing**

* **Scripting:** Python (`PyMuPDF`, `Pillow`) — авто-нарезка, микро-срез полей реза и удаление типографских меток с A4 PDF.

## 🚀 Быстрый запуск локально

### 1. Клонирование репозитория

```bash
git clone https://github.com/ТВОЙ_НИК/StayAwayOnline.git
cd StayAwayOnline
```

### 2. Запуск Бэкенда

```bash
cd stay-away-backend
npm install
npm run dev
```

*Сервер запустится на `http://localhost:3001`*

### 3. Запуск Фронтенда

В новом окне терминала:

```bash
cd stay-away-frontend
npm install
npm run dev
```

*Откройте в браузере `http://localhost:5173`*

## 🚀 План развития и будущие доработки / Roadmap

Список планируемых функций, улучшений и механик для будущих версий проекта:

### 🃏 Игровые механики и карты

- [ ] **Полный скриптинг карт Паники:** Реализация автоматического выполнения спец-эффектов для всех 12 карт Паники (массовый обмен по кругу в «Цепной реакции», рокировка игроков в «И это вы называете вечеринкой?» и др.).
- [ ] **Физическая перемена мест:** Динамическое изменение порядка игроков в массиве комнаты при розыгрыше карт *«Меняемся местами!»* и *«Сматывай удочки!»* с анимацией пересадки на 2D-столе.
- [ ] **Автоматика Заколоченных Дверей:** Автоматический пропуск фазы обмена между соседними игроками, заблокированными дверью.
- [ ] **Счетчик ходов Карантина:** Полноценный 3-ходовый таймер изоляции с автоматическим освобождением игрока.
- [ ] **Таймер на ход (Turn Timer):** Настраиваемый таймер обратного отсчета (30–60 сек.) для предотвращения затягивания игры.

### 🤖 Искусственный Интеллект

- [ ] **Автономные боты (Smart AI):** Написание базового алгоритма принятия решений для ботов (случайный сброс некритичных карт, автоматический обмен) для комфортной одиночной игры без ручного управления со стороны хоста.

### 🎨 Интерфейс и Графика (UI/UX)

- [ ] **Анимации движения карт (Framer Motion):** Плавный перелет карт из колоды в руку, а также визуальный обмен картами между аватарками игроков на столе.
- [ ] **Мобильная адаптация:** Оптимизация интерфейса 2D-стола и руки карт под вертикальные экраны смартфонов.
- [ ] **Звуковой движок (SFX):** Добавление звуков раздачи карт, шелеста обмена, гула пламени Огнемёта, тревоги Карантина и победных фанфар.

### 🌐 Мультиплеер и Сеть

- [ ] **Система восстановления сессий (Reconnection):** Возможность переподключиться к активной партии при обрыве связи или случайной перезагрузке страницы (по sessionToken в LocalStorage).
- [ ] **Встроенный Текстовый Чат:** Чат внутри игровой комнаты с функцией отправки быстрых эмодзи и реакций над аватарами игроков.
- [ ] **Поддержка Голосового Чата (WebRTC):** Голосовая связь прямо в браузере для психологического блефа и обсуждений.
- [ ] **Кастомные правила комнаты (House Rules):** Гибкая настройка параметров перед стартом (время хода, отключение определенных карт паники, открытые/закрытые роли после смерти).

### 🏆 Статистика и Дополнения

- [ ] **История матчей и Профиль:** Сохранение статистики побед Людей и Нечто (с использованием базы данных PostgreSQL / Supabase).
- [ ] **Выбор Аватаров:** Возможность выбирать кастомные аватарки персонажей в лобби перед началом игры.
- [ ] **Поддержка фанатских дополнений:** Возможность подключать кастомные колоды карт и расширения (например, *«Нечто: Из глубокой бездны»*).

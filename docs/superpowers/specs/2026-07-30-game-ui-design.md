# Спецификация дизайна AAA Game UI для настольной игры «Нечто» (Stay Away!)

**Дата**: 30 июля 2026 г.  
**Проект**: StayAwayOnline (Фронтенд на React + Vite + Zustand + Socket.io)  
**Статус**: Утверждено с пользователем  

---

## 1. Введение и Цель

Целью является создание высококачественного, атмосферного игрового интерфейса (AAA Game UI) для онлайн-версии настольной игры «Нечто» (Stay Away!), который превосходит стандартные браузерные интерфейсы, поддерживает эффект полного погружения в арктический хоррор, идеально адаптирован для мобильных устройств (смартфонов и планшетов) и вдохновлен стилистикой BoardGameArena (BGA) по наглядности игрового процесса.

---

## 2. Визуальный стиль и Атмосфера

- **Стилистика**: Мрачный арктический хоррор в стиле оригинальных физических карт из папки `public/cards/` (тёмно-синие, ледяные и стальные тона, следы изморози, деревянные текстуры барака, красные био-акценты заражения).
- **Типографика и акценты**: Чёткие современные шрифты с неоновой/свечевой подсветкой активных элементов.
- **Звук и VFX**: Лёгкие визуальные частицы метели/инея, звуковые эффекты раздачи карт, вспышки Огнемёта, сирены Паники и музыка победы/поражения через `@pixi/sound`.

---

## 3. Топология Игрового Стола (Option 1: Circular / Oval Table Layout)

1. **Главная арена (`OvalTable.tsx`)**:
   - Овальный стол по центру экрана.
   - Места игроков (от 4 до 12 человек) равномерно распределены по периметру овала.
   - На мобильных смартфонах в портретной ориентации овал автоматически перестраивается в компактный эллипс.

2. **Карточка Игрока (`PlayerSeat.tsx`)**:
   - Аватар/портрет игрока, имя, статус подключения и готовности.
   - Индикатор роли (Человек / Нечто / Заражённый — виден только соответствующим игрокам).
   - Оверлей Карантина (`QuarantineOverlay`): металлическая сетка рабица и счётчик оставшихся ходов.
   - Подсветка текущего хода: пульсирующий золотистый/красный контур и круговой таймер.

3. **Межкресельные баррикады (`BarredDoorSlot.tsx`)**:
   - В промежутках **между** соседними креслами игроков отображаются заколоченные двери (плашка с досками и гвоздями).
   - Заколоченная дверь блокирует обмен и розыгрыш направленных карт с соответствующим соседом.

4. **Центральный хаб (`TableCenterHub.tsx`)**:
   - Рубашка общей колоды брать карт (с эффектом морозного инея).
   - Стопка сброса (Discard pile).
   - Анимированная вращающаяся стрелка направления хода (по часовой / против часовой стрелки).

---

## 4. Система Инструкций и Ходов в стиле Board Game Arena (BGA Flow)

- **Верхний акцентный баннер (`ActionBanner.tsx`)**:
  - Находится в верхней части игрового экрана. Наглядно показывает текущее требуемое действие:
    - `Ваш ход: Возьмите 1 карту из колоды` *(подсвечивается колода в центре)*.
    - `Ваш ход: Выберите карту с руки для игры или сброса`.
    - `Выберите цель (соседнего игрока) для применения карты <Название>` *(разрешенные соседи подсвечиваются пульсирующими прицелами)*.
    - `Игрок X применил карту на вас! Выберите защиту или примите эффект`.
    - `Обмен картами: Выберите карту для передачи игроку Y`.
    - `Ожидание хода игрока Z...`

- **Интерактивные карты (`CardHand.tsx`)**:
  - Внизу экрана расположена рука игрока (ровно 4 карты).
  - Изображения карт берутся из `public/cards/*.png`.
  - При наведении/тапе карта приподнимается и выводит мини-меню: `[ Сыграть ]` / `[ Сбросить ]`.
  - Карты, недопустимые для разыгрывания в текущей фазе, слегка притемняются.

## 5. Компоненты UI и Модальные Окна

1. **`LobbyScreen.tsx`**:
   - Экран создания/входа в комнату, выбор ника и аватара, список подключенных игроков, добавление ботов, настройка задержки ботов, кнопка готовности/старта.
2. **`RevealModal.tsx`**:
   - Полноэкранный модальный оверлей с темным размытием для показов карт («Анализ», «Виски», «Подозрение», «Время признаний»).
3. **`ChatDrawer.tsx`**:
   - Выдвижная панель чата и системного лога событий (на мобильных — снизу, на ПК — справа).
4. **`GameOverModal.tsx`**:
   - Итоговый экран завершения игры с раскрытием всех карт и ролей выживших/погибших и анимацией победившей команды (Люди vs Нечто).

## 6. Мобильная Адаптивность и Touch UX

- Автоматическое масштабирование овала под вертикальные экраны устройств.
- Увеличенные области клика (touch targets) для карт и кнопок.
- Всплывающие шторки (bottom sheets) для чата и настроек.

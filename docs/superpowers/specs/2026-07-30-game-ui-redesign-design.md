**Дата:** 2026-07-30  
**Проект:** Stay Away Online («Нечто»)

## 1. Обзор и Цели

Цель данного проекта — кардинальный редизайн игрового интерфейса (Game UI) игры «Нечто» (Stay Away), превращающий стандартный плоский веб-интерфейс в глубоко атмосферный, производительный и визуально богатый гибридный игровое пространство.

### Ключевые требования:
1. **Интерактивный 2.5D Игровой стол на PixiJS v8:** 
   - Рендеринг деревянного стола барака в перспективе с физическими 3D-колодами событий и паники (`back.png`, `back_panic.png`).
   - Динамические преграды между игроками (Заколоченные двери, Карантин) с анимацией разлетающихся щепок при уничтожении топором.
   - Партикловая система визуальных эффектов (пламя огнемёта, брызги био-слизи заражения, падающий иней/пыль).
2. **Атмосферный React HUD (Dark Graphic Boardgame Style):**
   - Единый визуальный код, бережно воспроизводящий стиль оригинальных карт (`/public/cards`): тушевые контуры, выразительные тени, плакатная типографика.
   - Компас с анимированной стрелкой направления хода (По часовой / Против часовой стрелки).
   - Пошаговая плашка подсказок фазы хода (Шаг 1: Добор -> Шаг 2: Действие/Сброс -> Шаг 3: Обмен).
   - 3D-веер карт на руке с подсветкой типа карт (янтарная атака, синие действия, неоново-зеленые паника/инфекция).
3. **Кастомные Аватарки игроков (SIGame-style Avatar Picker):**
   - 1 универсальный дефолтный аватар-силуэт экспедитора.
   - Загрузка собственного фото (файл с устройства или URL) с встроенным удобным круговым кадрированием (Canvas Cropper) перед стартом игры.
   - Автоматическая синхронизация аватаров по Socket.io и маскирование в круглой жетонной плашке на PixiJS-столе.
4. **Мобильная Адаптивность (Mobile Responsiveness):**
   - Автомасштабирование PixiJS Canvas под размеры экранов телефонов и планшетов.
   - Сворачиваемый карт-веер с поддержкой touch-жестов («Drag-to-play», свайпы).
   - Боковые панели (Чат и Журнал радиограмм) в виде выезжающих мобильных шторок (Bottom Sheets / Drawers).

## 2. Архитектура Системы

### Стек технологий:
- **Frontend Framework:** React 19 + TypeScript + Vite
- **2D/2.5D Canvas Rendering Engine:** Pixi.js v8
- **UI Animation & Gesture Layer:** Framer Motion 12
- **Styling & Design Tokens:** Tailwind CSS 4
- **State Management:** Zustand 5
- **Networking:** Socket.io-client 4

## 3. Детализация компонентов

### 3.1 `<PixiGameBoard />` (Canvas Рендеринг)
- **Размеры & Resize:** Автоматически адаптируется под размер контейнера via `app.resizeTo`.
- **Слой 1 (`BackgroundLayer`):** Столешница из темного дерева с картой местности острова. Тень и шейдер пульсирующего света лампады.
- **Слой 2 (`DecksLayer`):** Спрайты колоды событий (`back.png`) и колоды паники (`back_panic.png`) под углом 2.5D с тенью и анимацией отлета карт.
- **Слой 3 (`PlayerTokensLayer`):**
  - Окружность/эллипс рассадки игроков.
  - Каждая фишка — круглый жетон с заклепками. Кастомный аватар загружается через `Pixi.Assets.load()`, на него накладывается круговая маска (`Graphics.drawCircle()`).
  - Активный игрок выделяется свечением ходового кольца.
- **Слой 4 (`ObstaclesLayer`):**
  - Графика деревянных досок («Заколоченная дверь») между слотами двух соседей. При вызове разрушения спавнится 15-20 летящих щепок на Pixi Ticker.
  - Металлическая решетка карантина поверх жетона игрока.
- **Слой 5 (`ParticlesLayer`):**
  - Эмиттер огня и дыма при использовании «Огнемёта».
  - Эмиттер зеленых капель слизи при заражении.

### 3.2 `<HandFanContainer />` & `<PlayerHand />`
- 4 карты на руке выстраиваются дугой с угловым смещением (`rotate(-9deg ... +9deg)`).
- Подсветка карт:
  - **Атака / Огнемёт:** Янтарно-красный неоновый контур.
  - **Действие:** Насыщенный океанический синий контур.
  - **Паника / Заражение:** Ядовито-зеленый контур.
- На сенсорных устройствах тап по карте выдвигает её вверх с отображением тултипа правил, свайп вверх подготавливает карту к розыгрышу.

### 3.3 Система Аватарок (Avatar Picker)
- Дефолтный аватар: силуэт исследователя в полярной куртке (`default_avatar.png`).
- Кастомный аватар:
  - Форма выбора в Лобби позволяет загрузить файл или указать URL.
  - Компонент `<AvatarCropper />` на HTML5 Canvas подрезает изображение до квадрата/круга с поддержкой масштаба и сдвига.
  - Итог конвертируется в сжатый dataURL (или передается по Socket.io) и синхронизируется у всех участников.

## 4. Мобильная адаптивность (Responsive Strategy)

| Элемент UI | Desktop (≥1024px) | Mobile Portrait (<1024px) |
| :--- | :--- | :--- |
| **PixiJS Canvas** | 100% центральной области | Авто-масштаб с сохранением пропорций стола |
| **Веер карт** | Широкая 3D-дуга внизу | Сложенный компактный веер, раскрывающийся по тапу |
| **Чат и Логи** | Фиксированные боковые панели | Выдвижные свайп-шторки (Bottom Sheet) |
| **Жесты** | Hover, клики кнопками мыши | Touch tap, swipe up (свайп для розыгрыша) |

## 5. План тестирования и верификации

1. **Компиляция & Сборка:** `npm run build` в `stay-away-frontend` без ошибок TypeScript и Vite.
2. **Производительность PixiJS:** Стабильные 60 FPS при вращении стола и спавне частиц огня/слизи.
3. **Адаптивность:** Тестирование в Chrome DevTools на пресетах iPhone 14 Pro (393px), iPad Air (820px) и Desktop 1920x1080.
4. **Синхронизация аватарок:** Проверка входа двух игроков с загрузкой кастомных аватаров и отображением их в жетонах PixiJS стола.
